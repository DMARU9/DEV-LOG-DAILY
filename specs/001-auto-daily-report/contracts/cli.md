# CLI Contract: dev-log-daily

**Version**: 1.0.0 | **Date**: 2026-06-20

---

## コマンドシグネチャ

```bash
dev-log-daily --config <PATH> [--date <YYYY-MM-DD>]
```

## オプション

| Option | Required | Type | Default | Description |
|--------|----------|------|---------|-------------|
| `--config` | ✅ YES | `PATH` | — | YAML設定ファイルのパス。指定がない場合は起動エラー。 |
| `--date` | ❌ NO | `YYYY-MM-DD` | 前日（ローカルタイムゾーン基準） | 日報対象日。単一日付のみ指定可能。 |

## 実行例

```bash
# 前日の日報を生成
dev-log-daily --config /path/to/config.yml

# 指定日の日報を生成
dev-log-daily --config /path/to/config.yml --date 2026-06-19
```

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | 正常終了（日報生成成功） |
| `0` | 正常終了（対象データなし） |
| `1` | 起動時エラー（設定ファイル未指定・不正・出力ディレクトリ不在） |
| `2` | パイプライン実行時エラー（LLM永続エラー・全リトライ失敗） |
| `3` | パイプライン実行時エラー（全データソース収集失敗） |

## 日報出力ファイルフォーマット（契約）

日報ファイル（`daily_report_YYYY-MM-DD.md`）は以下のセクション構造を持つ：

```markdown
# デイリー学習レポート - YYYY-MM-DD

## 📋 概要
（2〜3文の開発活動要約）

## 🛠 本日触れた技術・ツール
- **カテゴリ名**
  - 技術名: 何をしたか・何を学んだか

## 📚 学習内容
- **トピック**: 説明

## 💻 開発活動
- **プロジェクト名**
  - 作業内容

## 🔧 発生した問題と解決策
- **問題**: 説明
  - 解決策: 説明
```

- 文字コード: UTF-8
- 改行コード: LF（Unix）
- 上書き: 同名ファイルが存在する場合は上書き
